# บทเรียนของฉัน

เก็บเฉพาะสิ่งที่เรียนรู้แล้วอยากนำไปใช้กับงานครั้งหน้า เช่น:

- ฉันเปลี่ยนไอเดียกว้าง ๆ ให้เป็น feature เล็กได้อย่างไร
- ฉันทดลองงานที่ AI สร้างแล้วดูว่า “ตรงใจ” หรือไม่อย่างไร
- ครั้งหนึ่งฉันลืมปิด session แล้ว AI ช่วยกลับมาทำต่ออย่างไร

ไม่ต้องเขียนทุกวัน และไม่ต้องคัดลอกบทสนทนา ให้เขียนเมื่อมีสิ่งที่เข้าใจ
หรืออยากจำจริง ๆ
