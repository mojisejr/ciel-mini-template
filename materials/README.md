# วัตถุดิบของโปรเจกต์

วาง PDF, CSV, รูป, เสียง, โน้ต, ลิงก์ที่ export มา หรือหลักฐานอื่นไว้ใน
โฟลเดอร์นี้เมื่ออยากใช้กับโปรเจกต์

- ไฟล์ดิบในนี้ไม่ถูก commit ขึ้น Git
- บอก AI ให้ชัดว่าต้องการให้ใช้ไฟล์ใดและใช้ทำอะไร
- AI จะไม่เปิดอ่านทุกไฟล์เอง และจะไม่ส่งไฟล์หรือเนื้อหาออกจากโปรเจกต์
- ถ้ามีข้อมูลส่วนตัวหรือความลับ บอก AI ก่อนใช้ เพื่อช่วยกันเลือกสิ่งที่
  ควรบันทึกเป็นเพียงข้อสรุป ไม่ใช่ข้อมูลดิบ

ตัวอย่าง: “ใช้ PDF ใน `materials/` ช่วยสรุปปัญหาที่โปรเจกต์นี้ควรแก้ แล้ว
ช่วยอัปเดต `PROJECT.md` ให้ฉันตรวจ”
