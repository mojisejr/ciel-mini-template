# CIEL-mini — เริ่มโครงงานของฉันกับ AI

โฟลเดอร์นี้ช่วยให้ฉันสร้างโปรเจกต์กับ AI ได้ต่อเนื่อง แม้เริ่มแชตใหม่
หรือกลับมาในวันอื่น

## สร้างโครงงานของตัวเอง

ที่ [หน้า template บน GitHub](https://github.com/mojisejr/ciel-mini-template)
กด **Use this template → Create a new repository** ตั้งชื่อโครงงานของตัวเอง
แล้ว clone repository ใหม่นั้นลงเครื่อง ก่อนเปิดโฟลเดอร์ที่ clone ใน Codex
งานและประวัติ Git ของแต่ละคนจะแยกกัน

ถ้ามี PDF, CSV หรือรูปที่อยากใช้ ให้วางใน `materials/` ของโครงงานตัวเอง
แล้วบอก AI ว่าจะใช้ไฟล์ไหนเพื่ออะไร ไฟล์ดิบในโฟลเดอร์นี้ไม่ถูก commit

## เริ่มครั้งแรก

1. เปิดโฟลเดอร์นี้ใน Codex
2. เริ่มแชตใหม่แล้วส่งข้อความนี้:

   > ฉันเพิ่งเริ่มโปรเจกต์นี้ ช่วยอ่าน `README.md`, `AGENTS.md` และ
   > `PROJECT.md` ก่อน แล้วคุยกับฉันเพื่อทำให้ไอเดียชัดเจน อย่าเริ่มสร้าง
   > แอปจนกว่าฉันจะยืนยันว่าเราเข้าใจตรงกัน

3. เล่าไอเดียด้วยคำของตัวเอง ไม่ต้องรู้ศัพท์เทคนิคหรือเขียนโค้ดก่อน
4. อ่านสรุปที่ AI พูดกลับมา แก้สิ่งที่ไม่ตรง แล้วค่อยยืนยันให้เริ่มสร้าง

จากนั้นให้ AI ช่วยสร้างทีละส่วน ลองใช้สิ่งที่สร้างจริง แล้วบอกว่าอะไรตรงหรือ
ไม่ตรงกับที่คิด ก่อนจบรอบให้ AI บันทึกผลและ commit งานไว้

## กลับมาทำต่อ

เปิด Codex ในโฟลเดอร์เดิม แล้วบอกว่า:

> กลับมาทำโปรเจกต์ต่อ ช่วยอ่าน context ของโปรเจกต์ก่อน แล้วบอกฉันว่าเรา
> ทำถึงไหนและควรทำอะไรต่อ

AI จะอ่าน `PROJECT.md`, memory ล่าสุด และ Git ก่อนตอบ

## ไฟล์สำคัญ

- `AGENTS.md` คือข้อตกลงว่า AI ช่วยสร้างงานและส่งต่องานอย่างไร ไม่ใช่
  รายละเอียดของแอปหรือความจำทุกเรื่อง
- `PROJECT.md` คือสิ่งที่เราตกลงกันว่าโครงงานนี้กำลังสร้างอะไร
- `memory/` คือบันทึกสั้น ๆ ที่ช่วยให้กลับมาทำต่อได้
- `lessons/` คือสิ่งที่ฉันเรียนรู้และอยากเก็บไว้ใช้ครั้งหน้า
- `materials/` คือที่วาง PDF, CSV, รูป, โน้ต หรือหลักฐานที่อยากให้ AI
  ใช้เมื่อฉันบอก ไฟล์ดิบในนั้นไม่ขึ้น Git
- Git คือประวัติไฟล์ที่เปลี่ยนและย้อนดูได้ ส่วน `memory/` เก็บเหตุผล
  ข้อตกลง และสิ่งที่ยังค้าง ซึ่งดูจากโค้ดอย่างเดียวไม่ได้

การบันทึกไม่ใช่การบ้านเพิ่ม มันคือข้อความสั้น ๆ ที่ทำให้ฉันกับ AI วันหน้า
ไม่ต้องเริ่มคิดใหม่จากศูนย์

ก่อนบอกว่างานเสร็จ ลองตอบด้วยคำของตัวเองว่า “สร้างอะไร”, “ทำไมเลือกแบบนี้”
และ “ลองแล้วเห็นอะไร” AI ช่วยเขียนโค้ดได้เต็มที่ แต่คำตอบสามข้อนี้เป็นของเรา
