# เริ่มโปรเจกต์ของฉัน

โฟลเดอร์นี้ช่วยให้ฉันสร้างโปรเจกต์กับ AI ได้ต่อเนื่อง แม้เริ่มแชตใหม่
หรือกลับมาในวันอื่น

## เริ่มครั้งแรก

1. เปิดโฟลเดอร์นี้ใน Codex
2. เริ่มแชตใหม่แล้วส่งข้อความนี้:

   > ฉันเพิ่งเริ่มโปรเจกต์นี้ ช่วยอ่าน `README.md`, `AGENTS.md` และ
   > `PROJECT.md` ก่อน แล้วคุยกับฉันเพื่อทำให้ไอเดียชัดเจน อย่าเริ่มสร้าง
   > แอปจนกว่าฉันจะยืนยันว่าเราเข้าใจตรงกัน

3. เล่าไอเดียด้วยคำของตัวเอง ไม่ต้องรู้ศัพท์เทคนิคหรือเขียนโค้ดก่อน
4. อ่านสรุปที่ AI พูดกลับมา แก้สิ่งที่ไม่ตรง แล้วค่อยยืนยันให้เริ่มสร้าง

## กลับมาทำต่อ

เปิด Codex ในโฟลเดอร์เดิม แล้วบอกว่า:

> กลับมาทำโปรเจกต์ต่อ ช่วยอ่าน context ของโปรเจกต์ก่อน แล้วบอกฉันว่าเรา
> ทำถึงไหนและควรทำอะไรต่อ

AI จะอ่าน `PROJECT.md`, memory ล่าสุด และ Git ก่อนตอบ

## ไฟล์สำคัญ

- `PROJECT.md` คือสิ่งที่เราตกลงกันว่าโครงงานนี้กำลังสร้างอะไร
- `memory/` คือบันทึกสั้น ๆ ที่ช่วยให้กลับมาทำต่อได้
- `lessons/` คือสิ่งที่ฉันเรียนรู้และอยากเก็บไว้ใช้ครั้งหน้า
- `materials/` คือที่วาง PDF, CSV, รูป, โน้ต หรือหลักฐานที่อยากให้ AI
  ใช้เมื่อฉันบอก ไฟล์ดิบในนั้นไม่ขึ้น Git

การบันทึกไม่ใช่การบ้านเพิ่ม มันคือข้อความสั้น ๆ ที่ทำให้ฉันกับ AI วันหน้า
ไม่ต้องเริ่มคิดใหม่จากศูนย์
